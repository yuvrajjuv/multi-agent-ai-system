# 🤖 Multi-Agent AI System

An AI-powered multi-agent task orchestration system built using **Python, Streamlit, and LLMs**.  
This project demonstrates how multiple AI agents collaborate to break down user goals into structured tasks and generate intelligent responses.

# ⚙️ How It Works

1️⃣ User enters a goal or task  
2️⃣ Planner agent analyzes the request  
3️⃣ Goal is divided into structured sub-tasks  
4️⃣ AI agents collaborate to generate responses  
5️⃣ Final output is displayed through the Streamlit UI

# 📂 Installation & Setup

## Clone the Repository

```bash
git clone https://github.com/yuvrajjuv/multi-agent-ai-system.git
cd multi-agent-ai-system
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the App

```bash
streamlit run app.py
```
